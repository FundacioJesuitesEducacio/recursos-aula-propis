# Recursos d'aula propis (versió de prova)

Recursos interactius de la Fundació Jesuïtes Educació. Cada recurs és un sol fitxer HTML que no fa cap petició a tercers i no desa cap dada de l'alumnat.

Adreça: https://fundaciojesuiteseducacio.github.io/recursos-aula-propis/

| Recurs | Etapa | Carpeta |
|---|---|---|
| Les hores en català | Primària, 2n a 4t, i aula d'acollida | `hores/` |
| Laboratori del pèndol | Primària, 5è i 6è | `pendol/` |
| Circuits elèctrics senzills | Primària, 5è i 6è | `circuit/` |
| Els canvis de marxa d'una bicicleta | Primària, 5è i 6è | `bicicleta/` |

A cada carpeta, `index.html` és el tema clar i `fosc.html` el tema fosc.

La carpeta `cataleg/` és el catàleg de recursos d'aula: només hi ha els recursos publicables segons el protocol de revisió, amb les fitxes i les captures. Les fitxes i les puntuacions s'han generat amb IA i encara no s'han validat; les valoracions del professorat es desen només al navegador de cada docent.

Adreça del catàleg: https://fundaciojesuiteseducacio.github.io/recursos-aula-propis/cataleg/

**Versió de prova:**
- encara falten la revisió d'un docent de cada matèria i les proves amb alumnat;
- les pàgines porten `noindex`, perquè els cercadors no les indexin mentrestant.

## D'on surten

Aquests fitxers són còpies generades. Les fonts són al repositori intern de Recursos d'aula: el model, les fonts verificades, les comprovacions automàtiques i l'avaluació de cada recurs. S'hi copien amb `eines/publica-propis.js`. No s'han d'editar aquí directament.
